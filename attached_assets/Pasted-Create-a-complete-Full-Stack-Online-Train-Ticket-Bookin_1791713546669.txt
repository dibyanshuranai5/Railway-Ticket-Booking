Create a complete **Full-Stack Online Train Ticket Booking System**.

The project must be properly separated into frontend, backend, database, API integration, and feature-specific Java packages.

## 1. TECHNOLOGY STACK

### Frontend
- React.js
- JavaScript
- Normal CSS only
- DO NOT use Tailwind CSS
- Three.js / React Three Fiber for 3D effects
- GSAP for animations where useful
- Modern responsive UI
- Smooth transitions and interactive 3D railway/train elements

### Backend
- Java
- Spring Boot
- REST API
- Maven

### Database
- MongoDB
- Use MongoDB for:
  - User accounts
  - Authentication data
  - User profiles
  - Passenger information
  - Booking records
  - PNR records
  - Payment records
  - Ticket information

### Train API
Use a legitimate **IRCTC-compatible / railway Train API** for real-time railway information.

The API integration should support, where available:
- Train search
- Train schedule
- Train availability
- Seat availability
- Fare information
- Train running/runtime status

Keep the Train API configuration separate so that the API provider can be changed later.
